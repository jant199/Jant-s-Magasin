TUFT & CREATE — VERSION VISUELLE PLUS FIDÈLE
================================================

Cette version conserve la structure interactive (langues FR/EN/AR, produits, fenêtre de détail,
panier et commande WhatsApp) et réutilise des illustrations recadrées depuis votre maquette originale
pour garder son style dessiné à la main.

FICHIERS À METTRE À LA RACINE DU DÉPÔT GITHUB :
- index.html
- style.css
- app.js

DOSSIER assets :
- original-ui-reference.png : référence complète, ne s'affiche pas comme page.
- hero-studio.png : illustration de l'atelier extraite de la maquette.
- category-*.png : illustrations des cinq catégories.
- feature-*.png : illustrations des trois cartes.
- products/ : placez ici vos futures photos produit indépendantes.

DÉPLOIEMENT SANS RISQUE :
1. Ne supprimez pas votre index.html actuel avant d'avoir vérifié cette version.
2. Téléversez les trois fichiers à la racine du dépôt en remplaçant les versions précédentes seulement si vous êtes prêt.
3. Téléversez tout le dossier assets (ou tous les fichiers qu'il contient) en conservant exactement les noms et chemins.
4. Dans app.js, remplacez WHATSAPP_NUMBER par votre numéro WhatsApp international sans +, espaces ni tirets.
5. Vérifiez GitHub Actions, puis ouvrez https://jant199.github.io/Jant-s-Magasin/

IMPORTANT :
Cette version est une reconstruction éditable, pas une copie pixel-par-pixel de la maquette. Les illustrations
recadrées viennent de votre image d'origine afin de préserver davantage son identité visuelle. Les textes,
catégories et produits restent modifiables séparément.
